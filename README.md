# Campus Event Registration System

## Project Description
A simple Python command-line application for managing
student registrations in university workshops.

## Project Modules

- main.py: Handles user input, output, and menu navigation.
- student.py: Represents student information.
- registration.py: Handles validation, registration,
  duplicate checking, and participant listing.

## Features

- Register students for workshops.
- Validate required fields.
- Prevent duplicate registration numbers.
- Display registered participants.

## Technologies
- Python 3
- Git

## How to Run

1. Open the project directory.
2. Run the following command:

   python main.py

## Usage Example

1. Run the application:
   python main.py

2. Select Register Student.
3. Enter student name, registration number, and workshop.
4. Select Display Participants to view registrations.
5. Select Search Registration to find a student.
